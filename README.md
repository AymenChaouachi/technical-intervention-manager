# Technical Intervention Manager

## Description

This web application allows a company to manage technical interventions.

The system allows:

- Admin to create interventions and assign them to technicians
- Technicians to view their assigned interventions
- Technicians to update the status of their interventions

Each intervention follows this lifecycle:

To Do → In Progress → Done

---

## Technologies Used

- Node.js
- Express
- HTML / JavaScript (Frontend)

---

## How to Run

1. Install Node.js  
   https://nodejs.org

2. Install dependencies:

npm install


3. Start the server:

node server.js


4. Open in browser:

http://localhost:3000


---

## Features

- Create intervention
- Assign technician
- View assigned interventions
- Update intervention status
